# Skate Runner Art And Asset Plan

## When To Start Graphics

Start art once the core runner loop and camera feel are stable enough to know the asset list.

For this project, that means art can begin after these are playable:

- Three-lane behind-the-skater runner
- Swipe lane changes, ollie, flips, grind
- Hazard collisions
- Non-lethal score features
- Final mega-ramp bonus
- Basic scoring and restart loop

Do not wait until every system is final. Begin with replaceable style-test assets while gameplay tuning continues.

## Recommended Asset Strategy

Use marketplace/downloaded assets first, then make custom Blender assets only where the game's identity needs it.

Best early asset targets:

- Skateboard model
- Skater character model
- Basic skate animations
- City/street props
- Rails, benches, cones, barriers
- Coins/gold pickups
- UI icons and sound effects

Best custom Blender targets later:

- Main character silhouette
- Signature skateboard designs
- Unique hazard props
- Final bonus ramp/challenge set pieces
- Any branded or highly recognizable visual identity

## Visual Direction

Target a clean, readable mobile arcade look.

- Big readable hazards, not tiny pebbles
- Bright reward objects
- Strong lane readability
- Clear silhouettes at phone size
- Stylized street/skatepark objects
- Smooth animations over realistic simulation

## Hazard Ideas

Run-ending hazards should be big enough to read instantly.

- Construction barriers
- Parked scooters
- Trash can stacks
- Security blockers
- Wet concrete patches
- Road work signs
- Open manholes
- Delivery carts
- Bike racks
- Crowd barricades

## Non-Lethal Score Feature Ideas

These should reward skating through them instead of ending the run.

- Kicker ramps
- Stair gaps
- Manual pads
- Grind rails
- Ledge grinds
- Bank ramps
- Wallride panels
- Bonus coin lines
- Trick gates
- Speed boost arrows

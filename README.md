# SkateApp

SkateApp is a mobile endless runner game built in Unity. The player controls a skateboarder, avoids obstacles, and tries to survive for as long as possible while earning a higher score.

## Features

- Endless runner gameplay
- Player movement and jumping
- Randomized obstacles
- Score tracking
- Increasing difficulty
- Mobile controls
- Custom game assets and UI

## Built With

- Unity
- C#
- Git / GitHub

## Project Structure

The main Unity project is located in the `SkateRunnerUnity` folder.

Additional files in this repository contain planning, design, testing, and development notes for the project.
